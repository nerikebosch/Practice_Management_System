# Patient Management System

A full-stack web application designed to streamline the day-to-day operations of a medical practice. This Minimum Viable Product (MVP) handles patient relationship management, flexible scheduling, and simplified billing.

## 🚀 Core Features

*   **Patient Relationship Management:** Securely create, view, update, and manage patient demographics and records.
*   **Flexible Scheduling (Diary):** A digital calendar system allowing practitioners to book and modify daily appointments.
*   **Simplified Billing:** Automated generation of basic invoices linked to specific appointments and patient profiles.

## 🛠️ Tech Stack

This project is built using a modern, multi-tier architecture:

*   **Frontend:** Angular, TypeScript, HTML/SCSS
*   **Backend:** Python, FastAPI
*   **Database:** PostgreSQL
*   **Infrastructure:** Docker & Docker Compose

## 🏗️ Project Architecture

1.  **Frontend Interface:** An intuitive, component-based Angular dashboard.
2.  **RESTful API:** A fast, asynchronous Python backend handling business logic and routing.
3.  **Relational Database:** A robust PostgreSQL database for persistent, secure data storage.
4.  **Containerization:** The entire application environment is containerized using Docker for seamless local development and deployment.
